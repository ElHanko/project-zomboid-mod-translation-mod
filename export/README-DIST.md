# ElHanko Mod Translations

This mod adds translations for Project Zomboid, filling gaps in the vanilla
game's translations and covering the mods listed in `SUPPORTED-MODS.txt`.

Those mods are not included in this download. Install them separately if you
want to use them.

## Installation

Extract the archive and copy the `Project-Zomboid-Mod-Translations` folder to
the appropriate location:

- **Windows:** `%UserProfile%\Zomboid\mods\Project-Zomboid-Mod-Translations`
- **Linux:** `~/Zomboid/mods/Project-Zomboid-Mod-Translations`

The `common` and `42` subfolders should sit directly inside that folder.

Then enable **ElHanko Mod Translations** in Project Zomboid's mod menu.
Also enable each supported mod you want to play separately.

Place **ElHanko Mod Translations** as late as possible in the mod load order so it loads after the supported mods.

Have fun enjoying Project Zomboid in your language.
