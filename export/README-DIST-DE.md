# ElHanko Mod Translations

Diese Mod ergänzt deutsche Übersetzungen für Project Zomboid: fehlende
Übersetzungen des Vanilla-Spiels sowie Übersetzungen für die in
`SUPPORTED-MODS.txt` aufgeführten Mods.

Die unterstützten Mods sind nicht in diesem Download enthalten. Installiere
sie separat, wenn du sie verwenden möchtest.

## Installation

Entpacke das Archiv und kopiere den Ordner `Project-Zomboid-Mod-Translations`
an den passenden Ort:

- **Windows:** `%UserProfile%\Zomboid\mods\Project-Zomboid-Mod-Translations`
- **Linux:** `~/Zomboid/mods/Project-Zomboid-Mod-Translations`

Die Unterordner `common` und `42` müssen direkt in diesem Ordner liegen.

Aktiviere anschließend **ElHanko Mod Translations** im Mod-Menü von
Project Zomboid. Aktiviere auch die unterstützten Mods, die du spielen möchtest,
separat.

Platziere **ElHanko Mod Translations** möglichst weit hinten in der Mod-Ladereihenfolge, damit sie nach den unterstützten Mods geladen wird.

Viel Spaß dabei, Project Zomboid in deiner Sprache zu genießen.
